## 1. 一句话定位与基调 (High Concept)

> **「在昼夜交替的浮岛星澜地区，收服、培养你的灵兽，以实时动作战斗击败 8 大道馆、揭开『黯潮』之谜，成为星澜冠军。」**

| 维度 | 决策 |
|------|------|
| 品类 | 开放区域 3D 收集 / 养成 / 实时动作对战 RPG |
| 基调 | 明亮冒险 + 一丝悬疑（夜间「黯潮」） |
| 战斗 | Z-A 式**实时动作战斗**（自由走位 / 闪避 / 卡时机放招） |
| 探索 | 朱紫式**3D 开放区域** |
| 时长目标 | v1 主线 15–25 小时 + 收集/支线 |
| 平台 | v1 仅 Windows 单机 |
| 差异点 | 实时动作战斗 × 12 属性深度克制 × 昼夜规则驱动的收服约束 |

## 2. 目标玩家

- **核心**: 12–28 岁，玩过宝可梦/怪物猎人/原神的轻度–中度 RPG 玩家。
- **诉求**: 收集欲、养成成长曲线、战斗操作感、探索发现感。
- **非目标**: 硬核策略战棋玩家（本作偏动作而非回合博弈）、联机竞技玩家（v1 无联机）。

---

## 3. 核心乐趣支柱 (Fun Pillars)

设计取舍时以此排序，前一条优先级更高：

1. **发现与收集** — "下一只是什么？"的惊喜感。灵兽分布、稀有/传说/Alpha 的存在感。
2. **成长与养成** — 等级、进化、属性搭配带来的可见变强。
3. **操作与对抗** — 实时走位 + 闪避 + 时机放招的手感；克制带来的"打对属性秒杀"爽感。
4. **探索与节拍** — 大地图自由移动、昼夜变化、道馆进度 gate 的节奏感。
5. **叙事留白** — 「黯潮」悬念驱动主线，但不喧宾夺主。

## 4. 世界观设定 (星澜地区)

> 以下为设计设定（非剧情脚本），可随开发细化；所有名称可替换，不影响系统。

### 4.1 地理
- **星澜地区 (Stellara Region)**: 由若干**浮空岛屿群**与下方**低地森林/水域**组成。昼夜景观差异显著——白日浮岛金光、夜间被"黯潮"蓝黑雾笼罩。
- **生态分层**: 低地（木/水/岩系多见）、浮岛高地（风/光/冰系）、矿脉深渊（械/金/岩系）、雷暴峡谷（雷系）。

### 4.2 灵兽起源
- 灵兽统称 **灵兽 (Wispera)**，源于星澜的「星澜微粒」——一种昼夜交替时从天际洒落的微光，赋予生物特殊属性。
- 玩家身份: 新晋**灵兽驭使**，自三选一初始灵兽起步。

### 4.3 核心冲突 —「黯潮」
- 夜间，星澜微粒被污染形成**黯潮**：部分野生灵兽狂暴化（攻防提升、无法被收服）。
- 因此确立**硬性设计规则**: **夜间禁止收服**（见 §9）。这是把"世界观"直接转化为"玩法约束"的范例。

### 4.4 势力（占位）
- 道馆联盟、星空观测会（研究黯潮的学者阵营）、黯潮教团（反派，P 后续）。

## 6. 探索设计 (Overworld)

- **移动**: 走/跑、跳跃；镜头相对移动；带惯性平滑（`PlayerController.velocity_lerp`）。
- **相机**: 自研第三人称跟随（`CameraRig`），加速时 FOV 微增 + 行走 head bob。
- **遭遇**: 草丛/特定生态区 → 随机野怪；训练师 → 视线触发；Alpha/传说 → 固定点位或条件刷新。
- **交互点 (POI)**: 治疗点、道馆、商店、剧情 NPC、隐藏道具。
- **昼夜**: 全局时钟驱动光照/天空/雾；夜间改变生态（狂暴化、禁收服）。
- **HUD**: 小地图、当前首发灵兽、时间/天气、任务追踪（P7 完善）。

## 7. 灵兽设计 (Creature Design)

### 7.1 设计哲学
- **剪影优先**: 每种灵兽第一眼可辨（颜色 + 轮廓），占位期用色块/Mesh 区分。
- **属性即生态**: 属性与出没地形绑定（见 §4.1），强化"探索发现"。
- **进化即成长仪式**: 进化是养成的高光时刻，占位演出用缩放 + 换模。

### 7.2 属性系统（**12 属性**，数据驱动于 `data/type_chart.json`）

> ⚠️ 注意：本表为**真实已实现**的 12 属性（`type_chart.json` 含 金/冰，共 12 种）。`REQUIREMENTS.md` §5.2 旧文写"10 种占位"已过时，见 §14 修正说明。

**属性列表**: 炎 / 水 / 木 / 雷 / 岩 / 风 / 光 / 暗 / 械 / 灵 / **金** / **冰**

**克制设计意图** (以"强 2× / 弱 0.5×"表示，未列即 1×):
- **炎**: 强 木/风/械/金/冰；弱 水/岩 —— 广谱攻击属性，被水反制。
- **水**: 强 炎/岩/械；弱 木/雷/金/冰 —— 均衡但怕草雷。
- **木**: 强 水/岩；弱 炎/风/暗 —— 防守向，怕火。
- **雷**: 强 水/风/岩/金/冰；弱 械 —— 高速、覆盖面广，仅惧械。
- **岩**: 强 炎/雷/风；弱 木/水/械/金 —— 物理盾，被水木克制。
- **风**: 强 木/暗；弱 炎/岩/雷/金 —— 敏捷但脆，易被多属性压。
- **光**: 强 暗/灵；弱 岩/械 —— 暗/灵的克星。
- **暗**: 强 械/灵；弱 光/风 —— 与光互斥、与灵互克。
- **械**: 强 岩/暗/灵；弱 炎/水/雷 —— 工业属性，怕火水雷。
- **灵**: 强 暗/风；弱 炎/木/光 —— 神秘属性，怕火木光。
- **金**: 强 岩/暗/灵/械；弱 金/冰 —— **稀有强属性**（传说/首领多用），仅惧同类与冰。
- **冰**: 强 木/风/岩/灵/水；弱 炎/雷/金 —— 覆盖面广的控场属性。

**平衡观察（设计待办）**:
- **金** 当前过强（强 4 类、仅弱 2 类），且传说/Alpha/首领多为金系 → 建议后续给金系补弱点或限制传说出场；实时战中可用"属性护盾/环境"平衡。
- **暗↔灵** 互克 2×，且二者皆弱光 → 光系成为"暗灵队"的天然 counter，需注意光系分布。

### 7.3 灵兽图鉴（真实 27 种，数据驱动于 `data/creatures.json`）

**初始三选一（starter）**:
| 灵兽 | 属性 | 进化 | 进化为 |
|------|------|------|--------|
| 焰狐 flarefox | 炎 | Lv16 | 炎狼 flarewolf |
| 碧蛙 aqualeap | 水 | Lv16 | 碧骑士 aquaknight |
| 藤兔 vinelop | 木 | Lv16 | 藤王 vinelord |

**进化链（含二阶专属招式）**: 炎狼→`炎狼啸`、碧骑士→`碧潮崩`、藤王→`藤王缚`（皆为 75 威力专属）。

**野生常见（wild）**: 雷鼬/雷狮(雷)、岩龟(岩)、光鹿(光)、风雀/风翎(风)、暗犬(暗)、齿兽(械)、灵芽(灵)、雪绒兽/雪鬃兽(冰)、潮贝(水)、炽鼬/炎牙兽(炎)、霜豹(冰)、熔岩鳄(炎)。

**稀有/特殊定位**:
- **Alpha**: 钢颚王 steeljaw_king（金，lv18–22，boss，catch_rate 0.08）
- **Raid**: 晶甲兽 crystal_guardian（金，lv20–30，raid）
- **传说 Legendary**: 辉金龙 hui_jin_long（金，cover 封面灵兽）、黯钢兽 an_gang_shou（金，反派向）

### 7.4 特性 (Ability)
已实现特性: 猛火(炎)、蓄水(水)、叶绿素(木)、静电(雷)、坚硬(岩/械/金)、自然回复(光)、踏雪(冰)。
- 设计方向: 每灵兽 1 特性，开场或条件触发被动（如"猛火：HP 低于阈值时炎招威力提升"）。空缺特性（数据中为 ""）需后续补完。

## 8. 实时战斗设计 (Z-A 式)

### 8.1 进入与场景
- 遭遇 → 切换到**独立竞技场子场景**（非大地图），双方各 1+ 灵兽登场。
- 玩家**实时操控己方灵兽**自由移动（WASD + 镜头相对）。

### 8.2 控制方案（占位）
- 移动: WASD（镜头相对）
- 闪避: Shift（翻滚/冲刺，短暂无敌帧）
- 出招: 空格（当前选中招式，进入前摇→判定窗→后摇）
- 切换招式: 数字键 / 滚轮
- 换人/道具/投降: 战斗菜单（C/B 等，见 `InputSetup`）

### 8.3 出招时机与判定
- 招式有**前摇(蓄力) → 判定窗 → 后摇**三段；判定窗内命中生效。
- 命中取决于**距离 / 朝向 / 对方是否在闪避无敌帧**。
- **完美闪避**: 在敌方判定窗瞬间翻滚 → 触发反击/硬直（P3）。
- 冷却: 每招 `cooldown` 秒（`data/moves.json`），实时战中为能量恢复而非 PP。

### 8.4 属性克制在实时战中的体现
- 克制倍率直接乘入伤害（`core/combat.gd`），不因"实时"而失效。
- 设计目标: 走位拉扯 + 用克制属性对位 = 高风险高回报；用错属性 = 刮痧。

### 8.5 数值模型（设计公式）
```
伤害 = floor( (2*Level/5 + 2) * Power * Atk/Def / 50 + 2 )
        * 克制倍率 * 随机(0.85~1.0) * 时机加成(完美闪避/前摇完成度)
```
- 种族值: HP/攻/防/特攻/特防/速（实时战中"速"影响移动速度）。
- 招式三分类: 物理 / 特殊 / 变化（变化招无伤害但上状态）。

### 8.6 状态异常（P3）
中毒(持续 DOT)、麻痹(减速/偶尔定身)、睡眠(定身数秒)、灼烧(持续 DOT + 降攻)、冰冻(定身)。
- 实时战中表现为持续 DOT / 控制，而非回合跳过。
- 已实现带状态招式: `inferno`(灼烧30%)、`toxicspore`(中毒60%)、`thunderwave`(必定麻痹)、`hypno`(睡眠50%)。

### 8.7 换人与胜负
- 一方灵兽 HP 归零 → 可换下一只或投降。
- 全队倒下 → 送回治疗点（失败惩罚轻，鼓励重试）。

## 9. 收服与养成

### 9.1 收服（夜间受 §4.3 约束禁止）
- 流程: 削弱野生灵兽 HP + 施加异常状态 → 投掷灵球 → 按公式算成功率。
- **占位公式方向**: `成功率 = f(剩余HP比例, 状态加成, 球种 catch_mod, 种族 catch_rate)`。
  - 示例: `base = catch_rate * ball_mod * (1 - hp_ratio*0.8) * status_mult`
- **灵球梯度**（`data/items.json`，已实装）: 灵球(×1.0) / 优良球(×1.5) / 高级球(×2.0) / 远古球(×3.0, 对首领更易) / 至尊球(必定)。
- **夜间规则**: 处于夜晚阶段时收服入口被拦截，提示"夜晚黯潮汹涌，无法收服灵兽"。

### 9.2 等级 / 经验 / 进化
- 击败野怪获经验 → 达阈值升级 → 提升种族值对应实时属性。
- 进化: 等级(如 Lv16 三选一进化) / 道具 / 时段触发；占位演出缩放 + 换模。

### 9.3 队伍 / 存储 / 背包
- 出战上限 6，其余入存储箱；`SaveManager`(键 `Save`) 持久化。
- 道具（已实装 7 种）: 5 种球 + 伤药(恢复30) + 好伤药(恢复60)。

## 10. 道馆与进度 (P5)

- **8 座道馆**，每座对应一种属性倾向（建议分布: 炎/水/木/雷/岩/风/光/暗 各一，械/灵/金/冰 用于特殊馆或二周目）。
- 结构（朱紫式）: 进入 → 馆主**连续对战**（多只） → 胜得**徽章** → 解锁进度/新区域。
- 战斗采用 §8 实时机制；馆主 AI 用**行为树**（优先 Beehave）。
- 徽章存 `SaveManager`，作为主线进度 gate。

## 11. 叙事与任务 (P2)

## 12. 美术方向

- **风格**: 低多边形 / 扁平明快 + 程序生成占位；最终可换原创美术或 CC0 重制。
- **调色板**: 白日暖金 + 绿；夜间深蓝紫 + 黯潮幽光。
- **灵兽剪影**: 用 `visual.accent`(RGB) 与 `visual.scale` 在占位期区分（如炎狼 scale 1.18、accent 橙）。
- **环境**: 浮岛（高饱和、通透）、低地（茂密、暖）、矿脉（冷金属灰）、雷暴峡谷（高对比）。

---

## 13. 音频方向

- **红线**: 不使用任天堂/第三方版权音频。
- **当前方案**: `SoundBus` 优先读 `audio/<name>.wav`，缺失则**程序化合成**（规避版权）。
- **方向**: 原创 SFX（撞击/属性命中/收服/UI）；BGM 暂时移除（用户决策），后续用 CC0/原创。

## 15. 内容流水线 (Data-Driven Pipeline)

- **新增灵兽**: 在 `data/creatures.json` 追加条目（id/name/type/base 六维/catch_rate/ability/进化链/moves/视觉参数）。代码只读数据，无需改脚本。
- **新增招式**: `data/moves.json`（power/cooldown/accuracy/category/status）。
- **新增道具**: `data/items.json`（type/catch_mod 或 power/price）。
- **平衡调整**: 改 `type_chart.json` 倍率即可，战斗实时读取。
- **验收**: 每次内容增改后跑 `python harness/harness.py verify`（编译 + 冒烟 0 FAIL）作为门槛。

## 16. 设计验收指标 (Design Success Metrics)

| 指标 | 目标 | 测量方式 |
|------|------|----------|
| 收集完成度 | 首发版本图鉴 ≥ 27 种可获取 | 存档统计 |
| 战斗爽感 | 克制正确时击杀时间显著短于错位 | 内部测试 |
| 操作上手 | 新玩家 5 分钟内完成 1 场战斗 | 可用性测试 |
| 昼夜感知 | 玩家能说出"夜间不能收服"规则 | 问卷 |
| 崩溃率 | 全流程 0 未捕获崩溃 | `harness verify` + 日志 |
| 版权合规 | 100% 资源满足 §0 红线 | 资源审计 |
