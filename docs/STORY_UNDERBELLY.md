## 0. 灵感来源与设计红线（必读）

- **借的是骨架，不是皮肉。** 本文借鉴 *Grand Theft Auto V* 的**叙事结构与时调**：三主角切换叙事、渐升级的"行动"序列、黑色幽默与社会讽刺、"体面人"反派背后捅刀、最终大突袭（final score）。
- **全部内容原创。** 角色、地点、事件、对白均为星澜世界原创设定，**不出现任何 GTA / Rockstar 的名称、角色、地图或剧情**。这与 `GAME_DESIGN.md` §0 红线一致：机制/结构可借鉴，表达层必须原创；第三方 IP（含 Rockstar）素材一律不沿用。
- **为何能共存**：主线是"明亮冒险 + 一丝悬疑"，本支线是藏在光明下的"地下经济暗流"，二者基调对比互补，且不影响道馆进度（见 §6）。

## 1. 这条暗线是什么

星澜地区表面祥和，浮岛金光、道馆林立。但在旧港区与浮港贫民窟的阴影里，藏着一条**地下灵兽能源贸易链**：

> **澜生集团（Lumen Syndicate）**——一家以"清洁能源"自居的巨企，借"黯潮"恐慌低价收割狂暴野生灵兽、提炼星澜微粒能源高价贩卖，并暗中推动污染以维持垄断。

玩家可在主线之余，扮演一名周旋于各方势力的**赏金驭兽人**，接取"灰色委托"，逐步揭开澜生与黯潮教团的勾结。这条线用 **GTA5 式"接活 → 筹备 → 执行 → 余波"** 的节奏推进。

## 2. 三主角（切换叙事）

本支线采用**多主角切换**，三名角色各有独立章节，中段因一桩委托交汇，后段联手干一票大的。性格/处境对应 GTA5 的 Michael / Franklin / Trevor **原型**，但故事完全原创：

| 角色 | 代号 | 原型映射 | 身份与处境 | 角色弧光 |
|------|------|----------|-----------|----------|
| **谷深** | 「老酒」 | Michael（退隐高手） | 曾是为黯潮教团干脏活的王牌"猎潮人"，金盆洗手后在旧港区开小酒馆，有牵绊（养女 + 一只退役灵兽）。被旧债主拖回泥潭。 | 从逃避过去 → 重拾责任，为所爱之人再战。 |
| **阿澜** | 「澜仔」 | Franklin（街头野心家） | 浮港贫民窟长大的野路子驭兽少年，靠接灰色委托养活自己和一只小灵兽。一心想"翻身"。 | 从唯利是图 → 明白真正的羁绊不在钱，而在并肩的灵兽与伙伴。 |
| **焦三** | 「焦」 | Trevor（疯子 wildcard） | 失控的赏金猎人，家人死于黯潮教团之手，与教团有血海深仇。行事极端、不可预测，但对认定的人极度忠诚。 | 从被仇恨驱策 → 直面创伤，选择"为活人而战"而非"为死者复仇"。 |

> 切换机制（实现侧）：复用 `PlayerController` / `CameraRig`，按章节切换当前受控实体；三人共享同一背包/声望系统（见 §7）。

## 3. 行动序列（Heist 结构）

每个章节 = 一次**"行动"**。前期三人各自独立，中段交汇，后段联手。每次行动遵循统一节拍：

```
[接活] 联系人给委托 + 报酬
   ↓
[筹备] 选路线 / 选队员 / 选灵兽阵容（轻量简报 UI）
   ↓
[执行] 实时战斗 + 潜入 / 追逐 / 据点战（多线切换）
   ↓
[余波] 拿钱 / 结怨 / 解锁新线索，关系值变化
```

### 行动清单（渐升级）

- **行动 α ·「夜钓」**（阿澜篇 · 教学）
  阿澜接的第一单：潜入澜生一艘停泊的运输船，偷出一批被非法扣押的灵兽。教学：**潜入 + 非致命收服**，不打草惊蛇有额外报酬。

- **行动 β ·「旧港火并」**（谷深篇 · 教学）
  谷深的旧雇主借他"叛逃"要挟，夜袭酒馆。教学：**据点防守战**，保护养女与灵兽不被掳走。这一战让谷深明白躲不掉。

- **行动 γ ·「焦的复仇」**（焦三篇 · 转折）
  焦三单干，循线端掉一个教团据点，意外截获**澜生与教团勾结**的账本证据。但他失控焚毁现场，差点暴露三人。

- **行动 δ ·「三流合」**（交汇篇 · 多线）
  三人首次联手，劫下澜生一场公开"灵兽拍卖会"。关卡设计支持**实时切换三人**控场：阿澜潜入、谷深正面牵制、焦三外围清场。

- **行动 ε ·「内鬼」**（信任危机篇）
  盟友背叛，一人被捕。另两人营救，途中发现背叛者是被澜生拿捏了软肋（对应 GTA5 式"体面人背后捅刀"）。可选分支：救人与否影响 ζ 的可用路线。

- **行动 ζ ·「终局 · 澜生核心」**（Final Score）
  最终大突袭：攻入澜生浮空总部，**救出被囚的传说灵兽（辉金龙 / 黯钢兽）**、曝光丑闻、与操盘手正面对决。路线由前三人的关系值与 δ/ε 的选择决定（强攻 / 潜入 / 里应外合）。

## 4. 反派操盘手

- **表面人物**：澜生集团 CEO **晏照（Yan Zhao）**——衣冠楚楚、常年做慈善、媒体宠儿，讲话永远"为了星澜的明天"。
- **真相**：他才是**黯潮污染真正的推手**。逻辑很"资本"——制造能源危机 → 恐慌 → 民众接受澜生的"垄断式拯救" → 长期收割。对应 GTA5 的"体面人背后捅刀"反派原型（西装、笑容、捅刀）。
- **执行层**：黯潮教团教首「无面者」（戴面具，替澜生干脏活、背锅）。教团并非真正信仰黯潮，只是被晏照利用的工具——这一反转强化"反派不是怪物，是生意"的讽刺。

---

## 5. 基调与幽默（黑色幽默 + 讽刺）

- **反差萌**：高冷灵兽在犯罪现场打哈欠、阿澜的灵兽总在关键时刻拆台、潜入时灵兽不小心触发警报的社死瞬间。
- **媒体讽刺**：星澜晨报对主角团的态度在"通缉要犯"与"民间英雄"之间反复横跳，标题越来越离谱。
- **巨企讽刺**：澜生的 slogan 是"黯潮退散，光明自来"，实际靠黯潮发财；把灵兽称作"可再生产的清洁能源资产"，把收服叫"人才入库"。
- **委托人荒唐**：有 NPC 委托你"偷回被前任带走的灵兽"，理由只是"抚养费没给够"——用荒诞小委托冲淡主线的沉重。

---

## 6. 与主线（道馆旅程）的衔接

- 暗线**不影响**主线道馆进度，但提供丰厚回报：
  - **额外灵兽**：被救出的稀有/Alpha 灵兽可加入队伍。
  - **装备/球种**：澜生仓库里的特殊灵球与道具。
  - **传说线索**：被囚的辉金龙 / 黯钢兽与澜生直接相关，暗线推进解锁第三幕传说战前置。
- **关键交汇（分支结局）**：在第三幕冠军战前，玩家可选择**先引爆澜生丑闻**——会改变结局演出（晏照落网 vs 逍遥法外），体现"你不仅是冠军，也是掀翻黑幕的人"。

## 7. 实现提示（给后续 harness 任务）

- **多主角切换**：复用 `PlayerController` / `CameraRig`，新增 `current_actor` 切换点；三人共享背包与声望。
- **行动筹备 UI**：一个轻量"任务简报"界面（选路线 / 选队员 / 选灵兽阵容），数据驱动于 `data/quests.json`（新增 schema：`prep_options` / `routes` / `outcomes`）。
- **声望/关系系统**：三方关系值（谷深-阿澜-焦三）存 `SaveManager`（键 `Save`），影响 δ/ε/ζ 的可选路线与结局。
- **潜入机制**：新增"警戒值"轻量系统（侦测 → 警报 → 增援），可在 α / δ / ζ 潜入路线复用。
- **验收**：本支线内容增改后同样跑 `python harness/harness.py verify`（编译 + 冒烟 0 FAIL）为门槛。
